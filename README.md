# CSVの変更を見る v0.1

小さなCSVを2つ比べ、追加・削除された行と変わったセルを読むためのローカルブラウザツールです。表計算の式やコマンド操作を覚えずに、定期的なエクスポートの変化を確認したい人を想定しています。誰でも同じ手順で利用できます。

## 使い方

1. [index.html](index.html) をローカルのChromeまたはEdgeで開きます。サーバやインストールは不要です。
2. 「変更前のCSV」と「変更後のCSV」を選びます。
3. 両方のファイルで各行を一意に識別できるキー列（例: `id`）を選び、「変更を表示」を押します。
4. 画面上部のファイル名とキー列を確認し、追加・削除・変更・変更なしの件数と詳細を読みます。

試すときは [変更前の架空CSV](samples/old.csv) と [変更後の架空CSV](samples/new.csv) を使えます。キー列は `id` です。期待結果は追加1行（D）、削除1行（B）、変更1行（Aの`status`）、変更なし1行（C）です。

ファイルはブラウザのこのページ内で読み取ります。このページには外部スクリプト、通信処理、アカウント、分析機能、アップロード先はありません。選んだ内容や結果は保存・送信されません。共有端末では画面に表示された内容にご注意ください。

## 対応範囲

- UTF-8のカンマ区切りCSV。先頭BOM、LF/CRLF、引用符付きのカンマ・改行・二重引用符を受け付けます。
- 1行目は列名。両ファイルの列名集合は同じである必要がありますが、列の順序は違っても構いません。
- キー列は1列だけ選びます。各ファイル内で空欄・重複がない必要があります。前後の空白もキーの一部です。
- 各ファイル最大2 MiB、データ行最大10,000行、列最大50、各セル最大1,000 Unicode文字です。
- セルは文字列として完全一致で比べます。空セルは空文字列です。前後の空白を削らず、数値・日付・NULL等を推測しません。
- 変更件数は**変更された行数**です。1行で複数のセルが変わった場合、件数は1、詳細にはすべての変更セルを表示します。
- 詳細は一度に100件ずつ表示し、「前へ」「次へ」で移動します。件数は全行の比較結果です。

壊れたUTF-8/CSV、空・重複した列名、列数の違う行、列の追加・削除、空・重複したキー、上限超過はエラーとして比較を止めます。途中までの結果は表示しません。タブ区切り、Shift-JIS等の文字コード、複数キー、列名の変更、編集・マージ・エクスポート、履歴は対象外です。ファイルの内容はHTMLや数式として実行せず、文字として表示します。

## 開発用チェック

Node.jsがある開発環境では、外部パッケージなしでコアのテストを実行できます。利用者がNode.jsをインストールする必要はありません。

```text
node --test tests/core.test.mjs
```

テストはCSV解析、差分、境界エラー、架空サンプル、文字列の表示方針を確認します。ブラウザの画面操作そのものは自動化していません。
